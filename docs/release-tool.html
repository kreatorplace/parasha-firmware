Parasha Display · Release Tool

Everything here runs in this browser only. Your signing key is never sent anywhere.

1 · Your signing key (one time)

Displays only install updates signed with this key. Create it once, keep the file safe, and send only the public key (shown below) to Claude to build into the firmware.

Public key (safe to share):

Back up the key file (parasha-signing-key.pem) on a USB stick or in a password manager. If it's lost, displays can't be updated over WiFi until each one is reflashed by USB. Never upload it to GitHub.

2 · Make a release

Download these files, then publish them on GitHub:

    Promote a test release to everyone

    1. Open the release on GitHub → Edit (pencil icon).
    2. Untick Set as a pre-release, tick Set as the latest release.
    3. Update release. Every display installs it at its next check (just after midnight).
