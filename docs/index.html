Parasha Display · Install

Puts the display software on a XIAO ESP32-C3 by USB, from Chrome or Edge on a computer. After this, the display updates itself over WiFi.

Classic 4.2"

Black/white 4.2" panel

Use Chrome or Edge on a computer. Open this page over https.

Desktop 7.5"

Black/white 7.5" panel (800×480)

Use Chrome or Edge on a computer. Open this page over https.

Steps

  1. Plug the XIAO into the computer with a data USB-C cable.
  2. Click Install for your model, pick the port (often "USB JTAG/serial debug unit"), then Connect.
  3. When asked "Erase device?":
    • New board: yes (tick it).
    • Display that's already set up: no. WiFi, ZIP and family city are kept.
  4. Wait about 1 minute until it says Installation complete. Unplug and plug back in.

If it can't connect: hold B on the XIAO, tap R, release B, then click Install again.
